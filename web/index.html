VitaCabinet

Type what is printed on each box, one per line. VitaCabinet resolves each one against RxNorm, finds the boxes that are the same medicine under two names, and checks the FDA record for live recalls. It does not tell you what to take.

How it is built

VitaCabinet does not tell anyone what to take, what to stop, or what to throw away. It finds what is uncertain in a drawer and writes down the question to ask a pharmacist. That limit is enforced by which agent holds which tool, and it is tested.
